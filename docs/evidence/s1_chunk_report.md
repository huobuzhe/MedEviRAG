## 回链定位（locator）

| 指标 | 值 | 说明 |
| --- | --- | --- |
| bbox 退化（零面积/缺失）块数 | 0 | 退化即无法在 PDF 上高亮回链 |
| bbox 有效块数 | 4023 | 含表格块的真实表格矩形 |
| locator.block_index == 0 的块数 | 229 | 版面块序号透传后的残留（首块序号本就是 0） |
| 跨页块数 | 795 | 跨页块 bbox 只能定位首段，无法覆盖后几页 |

bbox 取值规则：

- 单页 chunk：取该页所有组成单元 bbox 的**并集**，高亮可盖住整块；
- 跨页 chunk：只保留**首段**矩形，本文如实声明「只能定位首段」；
- 表格块：pdfium find_tables() 的真实表格矩形；降级通道取 pdfplumber Table.bbox；
  两者都拿不到时退化为整页矩形（绝不写零矩形）。
