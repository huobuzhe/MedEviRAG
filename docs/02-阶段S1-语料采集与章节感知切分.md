## 1. 阶段目标与边界

### 1.1 阶段结束时"一定能做"的 5 件事

1. 一条命令可重放地从零采集 **10~20 份中文公开指南 PDF + 5~10 篇 PMC Open Access 英文文献**，产出 `data/raw/manifest.json`，含每份的来源 URL、抓取时间、sha256、许可与合规声明；重复执行不产生重复文件（sha256 去重），中断后重跑能续传。
2. 每份 PDF 都能解析成**版面块序列**（标题/正文/表格/图注 + 页码 + bbox + 字号 + 字体），落 `data/interim/<doc_id>.blocks.jsonl`；并且每份文档留一份可复核的**解析质量记录**（抽 3 页与肉眼对照的字符准确率）。
3. 能重建**章节树**：编号/字号/目录页三路证据合成层级，剔除页眉页脚，合并跨页标题，产出 `data/interim/<doc_id>.sections.json` 并同步写入 PG 的 `sections` 表，每节点带完整 `section_path` 数组。
4. 能按 **ADR-01 父子双层（small-to-big）** 切出子块，落 `data/processed/chunks.jsonl`，每行字段与 00 §6.1 **逐字段同名同类型**；`chunk_type` 为 `table` / `recommendation` 的块**零跨页合并**、超长时保留表头。
5. 每个 chunk 带 `doc_type / publisher / publish_year / lang / evidence_level / rec_strength / grade_system`，缺失一律写字符串 `"unknown"`（不写 `null`）；并产出一份**证据等级可得率**统计（如实报告，预期 20%~40%），作为 S4 `unknown` 分支的存在依据。

### 1.2 阶段结束时"一定还不做"的 4 件事

1. **不做 embedding、不建 Milvus/BM25 索引**——chunker 只把 `token_len` 算准，向量化属于 S2。
2. **不做重排、不做生成、不做引用校验**——`reranker` / `generator` / `verifier` 一行不写。
3. **不做 pgvector、不加 `chunks.embedding` 列**（00 ADR-07）：PG 里 `chunks.text` 存全量文本只为回链与审计。
4. **不做 OCR**：扫描件不修、不识别，只**识别出来并剔除**，并在报告里列出剔除清单。MinerU/OCR 属于 S1 之后的可选升级，不在 20h 预算内。

### 1.3 一句话定位

> 本章产物不是"一堆文本块"，而是**一等的章节树 + 它的叶子 chunk**。切分不是配置项，是数据建模。

## 4. 详细实施步骤

### 4.1 T1 · 语料采集器

**这一步要解决的问题**：把"语料从哪来、怎么合法地拿、怎么保证重跑不重复"固化成代码，而不是手工存 PDF。手工存的 PDF 没有来源、没有时间、没有 hash，后面出问题无法回溯。

**关键实现思路**

- 单一 UA：`MedEviRAG/0.1 (local research prototype)`。不伪装浏览器 UA——公开站点对脚本的容忍度取决于是否可识别。
- 限速：**每 host 串行 + 随机退避**。中文指南站点 `delay ∈ [1.5, 3.0]` 秒；NCBI E-utilities 无 API Key 时限 **3 req/s**，故 `delay ≥ 0.4s`；并遵守 `robots.txt`（`urllib.robotparser`）。
- 断点续传：`.part` 临时文件 + `Range: bytes=N-`；回 `206` 追加，回 `200` 说明服务端不支持 Range 则截断重下，回 `416` 说明已下完。
- 去重：落盘后算 `sha256` 与 manifest 比对，命中则删新文件、只更新 `last_seen_at`。**不按文件名去重**（同一份指南在不同站点文件名不同）。
- 合规：`manifest.json` 每条记录强制含 `license`、`compliance_note`、`redistribution: "prohibited"`。

```python
# src/medevirag/ingest/fetcher.py
from __future__ import annotations

import hashlib
import random
import time
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path

import httpx

UA = "MedEviRAG/0.1 (local research prototype; contact: local-user)"
PMC_OA = "https://www.ncbi.nlm.nih.gov/pmc/utils/oa/oa.fcgi"
PMC_EFETCH = "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi"

COMPLIANCE = ("仅用于本地 RAG 技术验证与效果评估，不做任何形式的分发、再发布或商用；"
              "文件不入版本库（.gitignore 排除）、不入制品、不随服务对外提供。")


@dataclass(slots=True)
class FetchRecord:
    doc_id: str
    tier: str                 # zh_guideline | pmc_oa
    source_url: str
    file_name: str
    sha256: str
    bytes: int
    fetched_at: str           # ISO8601 UTC
    license: str              # 中文指南多为 public-web-pdf；PMC 为 CC-BY 等
    compliance_note: str
    redistribution: str       # 固定 "prohibited"
    resume_from_bytes: int    # 本次续传起点，0 表示全新下载


def sha256_of(path: Path, chunk: int = 1 << 20) -> str:
    h = hashlib.sha256()
    with path.open("rb") as fh:
        while block := fh.read(chunk):
            h.update(block)
    return "sha256:" + h.hexdigest()


def download_resumable(
    client: httpx.Client,
    url: str,
    dest: Path,
    *,
    min_delay: float = 1.5,
    max_delay: float = 3.0,
    max_tries: int = 4,
) -> int:
    """返回本次续传起点字节数（0 = 全新下载）。失败抛 RuntimeError。"""
    dest.parent.mkdir(parents=True, exist_ok=True)
    part = dest.with_name(dest.name + ".part")
    start_bytes = 0
    for attempt in range(1, max_tries + 1):
        have = part.stat().st_size if part.exists() else 0
        headers = {"User-Agent": UA}
        if have:
            headers["Range"] = "bytes=" + str(have) + "-"
        try:
            with client.stream("GET", url, headers=headers,
                               timeout=httpx.Timeout(60.0)) as r:
                if r.status_code == 416:              # 服务端认为已下完
                    part.replace(dest)
                    return start_bytes
                if r.status_code == 206:
                    mode, start_bytes = "ab", have
                elif r.status_code == 200:
                    mode, start_bytes = "wb", 0       # 不支持 Range，必须重下
                else:
                    raise httpx.HTTPStatusError(
                        "unexpected " + str(r.status_code),
                        request=r.request, response=r)
                with part.open(mode) as fh:
                    for piece in r.iter_bytes(1 << 16):
                        fh.write(piece)
            part.replace(dest)
            time.sleep(random.uniform(min_delay, max_delay))
            return start_bytes
        except (httpx.HTTPError, OSError) as exc:
            wait = min(30.0, 2.0 ** attempt) + random.uniform(0, 1.0)
            print("  retry " + str(attempt) + "/" + str(max_tries)
                  + " in " + str(round(wait, 1)) + "s: " + type(exc).__name__)
            time.sleep(wait)
    raise RuntimeError("download failed after " + str(max_tries) + " tries: " + url)
```

PMC OA 走两段式：先用 OA service 确认该篇**确实在 OA 子集**并取回许可与包地址，再用 efetch 拉 JATS XML 全文（XML 比 PDF 更适合结构化抽取，也避开 PDF 解析风险）。

```python
def fetch_pmc_oa(client: httpx.Client, pmcid: str, out_dir: Path) -> FetchRecord:
    """pmcid 形如 PMC10293847。先查 OA 子集，再拉 JATS XML。"""
    r = client.get(PMC_OA, params={"id": pmcid},
                   headers={"User-Agent": UA}, timeout=60.0)
    r.raise_for_status()
    if "<error" in r.text:                 # 不在 OA 子集 → 直接拒绝，不留文件
        raise ValueError(pmcid + " not in PMC Open Access subset")
    # 响应中含 <license>CC BY-NC 4.0</license> 与 ftp 包地址
    license_text = _xml_text(r.text, "license") or "unknown"
    dest = out_dir / (pmcid + ".xml")
    xml = client.get(
        PMC_EFETCH,
        params={"db": "pmc", "id": pmcid.removeprefix("PMC"),
                "rettype": "xml", "retmode": "xml",
                "tool": "medevirag", "email": "local-user@example.invalid"},
        headers={"User-Agent": UA},
        timeout=120.0,
    )
    xml.raise_for_status()
    dest.write_bytes(xml.content)
    return FetchRecord(
        doc_id=pmcid, tier="pmc_oa", source_url=str(xml.request.url),
        file_name=dest.name, sha256=sha256_of(dest), bytes=dest.stat().st_size,
        fetched_at=datetime.now(timezone.utc).isoformat(timespec="seconds"),
        license=license_text, compliance_note=COMPLIANCE,
        redistribution="prohibited", resume_from_bytes=0,
    )
```

**坑**

- `httpx` 默认读环境变量 `HTTPS_PROXY`。S1 里只有 PMC/NCBI 需要代理，中文站点直连更快——所以**必须用 `httpx.Client(proxy=...)` 按 host 显式配**，不要依赖全局环境变量（这正是 00 §2.3 那条警告的落点）。
- 中文指南站点常返回 `Content-Type: application/octet-stream` 或直接给 HTML 错误页；落盘后要**校验 PDF 魔数** `%PDF-`，否则 `fitz.open` 会抛 `FileDataError`。
- 文件名里的 `?` / `&` / 中文要 sanitize，否则 Windows 上路径非法（`< > : " | ? *` 全部非法）。
- `.gitignore` 追加三行：`data/raw/`、`data/interim/`、`data/processed/`；但 **`data/reports/` 不排除**（报告要进仓库当证据）。

### 4.2 T2 · PDF 解析与版面块

**这一步要解决的问题**：拿到"页 → 块 → 行 → span"的原始结构，加工成**语义单位的版面块**，并给每块打上足够属性（字号、字体、是否加粗、bbox），供 T3 判标题、供 S3 回链高亮。

**关键实现思路**

- `page.get_text("dict")` 给到 `blocks[] → lines[] → spans[]`，每个 span 带 `size`（pt）、`font`、`flags`（bit0=superscript，bit1=italic，bit4=bold）。**块级字号取"按字符数加权的众数"**，不能取最大——上标（如 `mmHg` 的角标）会把最大值拉偏。
- 表格：先 `page.find_tables()`（pymupdf ≥1.23.8），把表格 bbox 记下来，**并把落在 bbox 内的文本块从正文流剔除**，避免表格内容被当正文重复计一次。`find_tables` 空则降级 `pdfplumber.Page.extract_tables()`；两者都空则该区域标 `figure_caption` 并裁图存档。
- 扫描件检测（阈值必须具体）：**单页文本层字符数 < 80 → 该页无有效文本层**；**全文档平均 < 150 字符/页 → 判定整份为扫描件，直接剔除**，写进 `manifest.json` 的 `rejected` 列表，不进后续流程。
- 解析质量评估：抽 **3 页**（第 1 页、中间页、表格最密的一页），人工把该页正文逐字录入 `tests/fixtures/ingest/<doc_id>_p<N>_ref.txt`，用 Levenshtein 距离算字符准确率。**<95% 就换解析器**（pymupdf → MinerU/unstructured），这是 00 §3 那条 🔴 高风险项的对策原文。

```python
# src/medevirag/ingest/parser.py
from __future__ import annotations

import unicodedata
from collections import Counter
from dataclasses import dataclass
from pathlib import Path

import fitz  # pymupdf 的兼容 import 名

SCAN_CHARS_PER_PAGE = 150      # 整份文档平均字符数/页 低于此值 → 扫描件
SCAN_PAGE_CHARS = 80           # 单页正文块字符数 低于此值 → 该页无文本层


@dataclass(slots=True)
class LayoutBlock:
    page: int                  # 1-based
    block_index: int           # 页内序号，与 page 一起唯一定位
    kind: str                  # body | title | table | figure_caption
    text: str
    bbox: tuple[float, float, float, float]
    size: float                # 字符数加权众数字号
    font: str
    bold: bool
    n_chars: int


def _weighted_size(spans: list[dict]) -> tuple[float, str, bool]:
    sizes: Counter[float] = Counter()
    fonts: Counter[str] = Counter()
    bold_chars = 0
    total = 0
    for sp in spans:
        n = len(sp["text"].strip())
        if not n:
            continue
        sizes[round(sp["size"], 1)] += n
        fonts[sp["font"]] += n
        total += n
        if sp["flags"] & 2 ** 4:            # bit4 = bold
            bold_chars += n
    if not total:
        return 0.0, "", False
    return sizes.most_common(1)[0][0], fonts.most_common(1)[0][0], bold_chars / total > 0.6


def render_table(rows: list[list[str | None]]) -> str:
    """表格渲染成管道分隔文本，首行作表头，单元格内换行压成空格。"""
    clean = [[" ".join((c or "").split()) for c in row] for row in rows]
    head, body = clean[0], clean[1:]
    lines = ["| " + " | ".join(head) + " |", "|" + "---|" * len(head)]
    lines += ["| " + " | ".join(r) + " |" for r in body]
    return "\n".join(lines)


def extract_blocks(pdf_path: Path, doc_id: str) -> tuple[list[LayoutBlock], dict]:
    doc = fitz.open(pdf_path)
    blocks: list[LayoutBlock] = []
    chars_per_page: list[int] = []
    for pno in range(1, doc.page_count + 1):
        page = doc[pno - 1]
        tabs = page.find_tables().tables
        table_rects = [fitz.Rect(t.bbox) for t in tabs]
        page_chars = 0
        for bi, b in enumerate(page.get_text("dict")["blocks"]):
            if b["type"] != 0:                       # 图片块留给图注逻辑
                continue
            spans = [sp for ln in b["lines"] for sp in ln["spans"]]
            text = "".join(sp["text"] for sp in spans).strip()
            if not text:
                continue
            rect = fitz.Rect(b["bbox"])
            if any(rect in tr for tr in table_rects):  # 表格内部文本，另行抽取
                continue
            size, font, bold = _weighted_size(spans)
            page_chars += len(text)
            blocks.append(LayoutBlock(
                page=pno, block_index=bi, kind="body", text=text,
                bbox=(round(rect.x0, 1), round(rect.y0, 1),
                      round(rect.x1, 1), round(rect.y1, 1)),
                size=size, font=font, bold=bold, n_chars=len(text),
            ))
        for ti, tab in enumerate(tabs):
            rows = tab.extract()
            blocks.append(LayoutBlock(
                page=pno, block_index=10_000 + ti, kind="table",
                text=render_table(rows),
                bbox=tuple(round(v, 1) for v in tab.bbox),
                size=0.0, font="", bold=False,
                n_chars=sum(len(c or "") for r in rows for c in r),
            ))
        chars_per_page.append(page_chars)
    mean = sum(chars_per_page) / max(1, doc.page_count)
    stats = {
        "doc_id": doc_id,
        "page_count": doc.page_count,
        "chars_total": sum(chars_per_page),
        "chars_per_page_mean": round(mean, 1),
        "empty_pages": [i + 1 for i, c in enumerate(chars_per_page) if c < SCAN_PAGE_CHARS],
        "is_scanned": mean < SCAN_CHARS_PER_PAGE,
    }
    return blocks, stats
```

```python
import re
import unicodedata


def _norm_for_cer(s: str) -> str:
    """NFKC 归一 + 去全部空白。空白必须去，否则段间距会被算成错字。"""
    return re.sub(r"\s+", "", unicodedata.normalize("NFKC", s))


def char_accuracy(ref: str, hyp: str) -> float:
    """字符准确率 = 1 - 编辑距离 / 参考长度。"""
    import Levenshtein
    r, h = _norm_for_cer(ref), _norm_for_cer(hyp)
    if not r:
        return 1.0
    return max(0.0, 1.0 - Levenshtein.distance(r, h) / len(r))


def evaluate_parse_quality(doc_id: str, pages: dict[int, str],
                           refs: dict[int, str], threshold: float = 0.95) -> dict:
    """refs: {页码: 人工录入的该页正文}。返回逐页准确率与是否达标。"""
    per_page = {p: round(char_accuracy(refs[p], pages.get(p, "")), 4) for p in refs}
    worst = min(per_page.values()) if per_page else 0.0
    return {"doc_id": doc_id, "per_page": per_page, "min": worst,
            "passed": worst >= threshold, "threshold": threshold}
```

**坑**

- `pymupdf` 与 `fitz` 是两个 import 名但同一个包；**PyPI 上另有一个叫 `fitz` 的无关包**，装了它会 `ImportError: cannot import name 'Document' from 'fitz'`。只装 `pymupdf`，代码首选 `import pymupdf`。

### 4.3 T3 · 章节树重建（本阶段最硬的一块）

**这一步要解决的问题**：把线性 block 流还原成**层级结构**。难点不在"识别一个标题"，而在**四类噪声同时存在**：多套编号体系混用、字号不可靠、跨页标题被切断、页眉页脚插在正文里。

#### 4.3.1 编号正则（四套体系，必须都覆盖）

| 体系 | 样例 | 提取的 `section_no` |
|---|---|---|
| 多级阿拉伯 | `3.2.1 诊室血压` | `3.2.1` |
| 中文章节 | `第三章 诊断与评估`、`第3节 血压测量` | `第三章` |
| 中文括号 | `（二）药物治疗`、`(2) 联合用药` | `（二）` |
| 中文顿号 | `一、一般人群` | `一、` |

```python
# src/medevirag/ingest/sectionizer.py
from __future__ import annotations

import re
import unicodedata

# 每项：(体系名, 正则, 编号所在组)
NUM_PATTERNS: list[tuple[str, re.Pattern[str]]] = [
    ("cn_chapter", re.compile(
        r"^第\s*([一二三四五六七八九十百零〇\d]{1,4})\s*([章节部篇])\s*[、\.．:：]?\s*(.*)$")),
    ("multi_arabic", re.compile(
        r"^(\d{1,2}(?:\.\d{1,2}){0,4})\s*[、\.．]{0,2}(?=\D)(\S.{0,60})$")),
    ("cn_paren", re.compile(
        r"^[（(]\s*([一二三四五六七八九十]{1,3}|\d{1,2})\s*[）)]\s*(\S.{0,60})$")),
    ("cn_dunhao", re.compile(
        r"^([一二三四五六七八九十]{1,3})\s*[、．\.]\s*(\S.{0,60})$")),
]

_CN_DIGIT = {"零": 0, "〇": 0, "一": 1, "二": 2, "三": 3, "四": 4,
             "五": 5, "六": 6, "七": 7, "八": 8, "九": 9}
_CN_UNIT_LEVEL = {"章": 1, "篇": 1, "部": 1, "节": 2}


def cn2int(s: str) -> int:
    """仅覆盖 1~99（指南章节编号不会更大）：'十一'→11，'二十'→20，'十'→10。"""
    if s.isdigit():
        return int(s)
    if "十" in s:
        a, _, b = s.partition("十")
        return (_CN_DIGIT[a] if a else 1) * 10 + (_CN_DIGIT[b] if b else 0)
    return _CN_DIGIT.get(s, 0)


def match_number(text: str) -> tuple[str, str, int] | None:
    """返回 (体系, 归一化编号串, 隐含层级)；不命中返回 None。"""
    t = unicodedata.normalize("NFKC", text.strip())
    for name, pat in NUM_PATTERNS:
        m = pat.match(t)
        if not m:
            continue
        if name == "cn_chapter":
            no, unit = m.group(1), m.group(2)
            return name, "第" + no + unit, _CN_UNIT_LEVEL[unit]
        no = m.group(1)
        if name == "multi_arabic":
            return name, no, no.count(".") + 1
        if name == "cn_paren":
            return name, "(" + no + ")", 3
        return name, no + "、", 3
    return None
```

> 关键防误判：`multi_arabic` 用 `\d{1,2}` 限两位 + `(?=\D)` 前瞻，保证 `140/90 mmHg`、`2024年修订版`、`5mg 每日一次` 都**不**被吃成标题。这两条必须在 `test_sectionizer.py` 里各有一条反例用例。

#### 4.3.2 字号层级（不可靠，只能当辅助证据）

中文指南大量使用"加粗不加字号"，所以**字号不能独立定层级**。做法：

1. 统计全文字符数加权的众数字号 → `body_size`；
2. 候选标题块与 `body_size` 的比值分三档：`≥1.6` 强信号、`1.2~1.6` 弱信号、`≈1.0 且 `bold=True` 弱信号；
3. 最终 `level` **优先取编号深度**，编号缺失时才用字号兜底（"参考文献""附录A""致谢"这类无编号标题）。

```python
def heading_level(block, body_size: float) -> int | None:
    """block 是 LayoutBlock；返回层级或 None（不是标题）。"""
    hit = match_number(block.text)
    ratio = block.size / body_size if body_size else 1.0
    size_level = 1 if ratio >= 1.6 else 2 if ratio >= 1.2 else (
        3 if (block.bold or ratio >= 1.05) else None)
    looks_like_heading = (
        2 <= block.n_chars <= 40
        and not re.search(r"[。；，,、]\s*$", block.text)
        and not block.text.startswith(("表", "图"))      # 表题/图题不是章节
    )
    if not looks_like_heading:
        return None
    if hit is not None:
        return hit[2]                                    # 编号深度优先
    return size_level                                    # 无编号时字号兜底
```

#### 4.3.3 目录页对齐（交叉校验 + 算页码偏移）

目录页典型形态是"标题 + 点线/空格 + 页码"。用途两个，务必分清：

- **校验**：从目录抽出的 `(title, printed_page)` 与正文抽出标题做归一化匹配（NFKC + 去空白 + 去点线），**匹配率 ≥80% 才认为目录可信**，否则弃用目录只靠正文。
- **算页码偏移**：PDF 第 N 页往往不是印刷页码第 N 页（版权页、序言占位）。用目录的"标题→印刷页码"与正文的"同一标题→PDF 页序号"配对，取 `offset = printed_page - pdf_index` 的**众数**。但 00 §6.1 的 `"page": 27` 必须是**回链可用的 PDF 页序号**，所以最终落库一律是 PDF 序号，印刷页码只用于校验。

```python
TOC_LINE = re.compile(
    r"^(?P<title>[\u4e00-\u9fa5A-Za-z0-9（）()、．\.\s]{2,60}?)[\s.·…]{3,}(?P<page>\d{1,4})\s*$")


def _norm_title(t: str) -> str:
    t = unicodedata.normalize("NFKC", t)
    return re.sub(r"[\s.·…]+", "", t)


def parse_toc(pages_text: dict[int, str]) -> list[tuple[str, int]]:
    """pages_text: {PDF 页码: 该页纯文本}。返回 [(归一化标题, 印刷页码)]。"""
    out: list[tuple[str, int]] = []
    for pno in sorted(pages_text):
        head = pages_text[pno][:40].replace(" ", "")
        if not ("目录" in head or "目次" in head or "CONTENTS" in head.upper()):
            continue
        for ln in pages_text[pno].splitlines():
            m = TOC_LINE.match(ln.strip())
            if m:
                out.append((_norm_title(m.group("title")), int(m.group("page"))))
        if len(out) >= 5:            # 抽到 5 条以上才认这一页是目录
            break
    return out


def page_offset(toc: list[tuple[str, int]],
                headings: list[tuple[str, int]]) -> int:
    """headings: [(归一化标题, PDF 页序号)]。返回印刷页码 - PDF 序号的众数偏移。"""
    from collections import Counter
    index = {t: p for t, p in headings}
    deltas = Counter(index[t] - pp for t, pp in toc if t in index)
    return deltas.most_common(1)[0][0] if deltas else 0


def toc_trusted(toc: list[tuple[str, int]], headings: list[tuple[str, int]],
                min_match: float = 0.80) -> bool:
    if not toc:
        return False
    index = {t for t, _ in headings}
    hit = sum(1 for t, _ in toc if t in index)
    return hit / len(toc) >= min_match
```

#### 4.3.4 跨页标题合并与段落续接

两类"跨页"必须分开处理：

- **标题被分页切断**（`"3.2.1 诊"` / `"室血压"`）：上一页末块是标题候选、字数 ≤8、下一页首块字号与字体**完全相同**、且不以编号开头 → 拼接后重新判标题。
- **正文段落跨页**：上一页末块不以 `[。！？；：)】」』]` 结尾，下一页首块不以编号开头 → 合并为一个块链（只为切分时句子不断，不改变 section 归属）。

```python
SENT_END = re.compile(r"[。！？；：\)】」』!?;:]\s*$")


def merge_cross_page(blocks: list) -> list:
    """就地合并跨页的标题碎片与段落链。"""
    merged: list = []
    for b in blocks:
        if merged:
            prev = merged[-1]
            same_style = abs(prev.size - b.size) < 0.2 and prev.font == b.font
            if (b.page == prev.page + 1 and same_style
                    and len(prev.text) <= 8
                    and match_number(b.text) is None):
                prev.text += b.text                    # 标题碎片拼接
                prev.n_chars = len(prev.text)
                continue
            if (b.page == prev.page + 1
                    and prev.kind == "body" and b.kind == "body"
                    and not SENT_END.search(prev.text)
                    and match_number(b.text) is None):
                prev.text += b.text                    # 段落续接
                prev.n_chars = len(prev.text)
                prev.bbox = (prev.bbox[0], prev.bbox[1], b.bbox[2], b.bbox[3])
                continue
        merged.append(b)
    return merged
```

#### 4.3.5 页眉页脚剔除（重复行检测，不硬编码坐标）

不要写"y0 < 60 就删"——不同出版社版心不同。做法是**位置先验 + 跨页频次**：

- 只统计位于页面**顶部 8%** 或**底部 8%** 的行；
- 归一化：数字统一替换成 `#`、去所有空白、NFKC（这样 `中国高血压防治指南 2024 第 27 页` 与 `...第 28 页` 归为同一键）；
- 同键出现页数 `≥3` 且 `出现页数 / 总页数 ≥ 0.30` → 判为页眉/页脚；
- 另无条件剔除纯页码行：`^[\-—–]?\s*\d{1,4}\s*[\-—–]?$`。

```python
from collections import Counter


def _margin_key(t: str) -> str:
    t = unicodedata.normalize("NFKC", t)
    t = re.sub(r"\d+", "#", t)
    return re.sub(r"\s+", "", t)


def detect_repeated_margins(
    lines_by_page: dict[int, list[tuple[str, float, float, float]]],
    *, top: float = 0.08, bottom: float = 0.92,
    min_pages: int = 3, min_ratio: float = 0.30,
) -> set[str]:
    """lines_by_page: {页码: [(文本, y0, y1, 页高), ...]} → 应剔除的归一化键集合。"""
    seen: Counter[str] = Counter()
    for _pno, lines in lines_by_page.items():
        for text, y0, y1, h in lines:
            if not text.strip():
                continue
            if y0 < h * top or y1 > h * bottom:
                seen[_margin_key(text)] += 1
    n = max(1, len(lines_by_page))
    return {k for k, c in seen.items() if c >= min_pages and c / n >= min_ratio}


PURE_PAGE_NO = re.compile(r"^[\-—–]?\s*\d{1,4}\s*[\-—–]?$")


def is_pure_page_number(text: str) -> bool:
    return bool(PURE_PAGE_NO.match(text.strip()))
```

#### 4.3.6 用栈装配树，落盘并写 PG

```python
from dataclasses import dataclass, field


@dataclass(slots=True)
class Section:
    section_id: str                 # "<doc_id>#<section_no>"
    doc_id: str
    section_no: str
    title: str
    level: int
    page_start: int
    page_end: int
    order_index: int
    parent_section_id: str | None
    section_path: list[str]         # 完整路径，chunker 直接用
    block_ids: list[str] = field(default_factory=list)   # "page:block_index"


def build_sections(doc_id: str, headings: list[tuple], blocks: list) -> list[Section]:
    """headings: [(LayoutBlock, level, section_no, title)]，按阅读顺序。"""
    root = Section(doc_id + "#root", doc_id, "", "ROOT", 0,
                   blocks[0].page, blocks[-1].page, 0, None, [])
    flat: list[Section] = [root]
    stack: list[Section] = [root]
    for order, (blk, level, no, title) in enumerate(headings, start=1):
        while len(stack) > 1 and stack[-1].level >= level:
            closed = stack.pop()
            closed.page_end = max(closed.page_end, blk.page - 1) if blk.page > closed.page_start \
                else closed.page_start                                  # 回填 page_end
        parent = stack[-1]
        sec = Section(
            section_id=doc_id + "#" + no.replace(" ", ""),
            doc_id=doc_id, section_no=no, title=title, level=level,
            page_start=blk.page, page_end=blk.page, order_index=order,
            parent_section_id=None if parent is root else parent.section_id,
            section_path=([] if parent is root else parent.section_path)
                          + [(no + " " + title).strip()],
        )
        flat.append(sec)
        stack.append(sec)
    while len(stack) > 1:
        closed = stack.pop()
        closed.page_end = blocks[-1].page
    for sec in flat[1:]:
        _assign_blocks(sec, blocks)     # 按 heading 顺序与页码把 block 归入最深节
    return flat
```

     "section_path": ["3 诊断与评估", "3.2 血压测量", "3.2.1 诊室血压"]}
  ]
}
```

**坑**

- `section_path` 元素格式统一为 `"<编号> <标题>"`，chunker 直接取最后一段做 `context_header`；**不要**在 chunker 里重新拼编号，否则两处逻辑不一致。
- PG 的 `sections` 表按 00 §6.2 是 `section_id PK, doc_id FK, parent_section_id, section_no, title, level, page_start, page_end, order_index`，字段名一字不能改。
- `page_end` 必须**在栈弹出时回填**，否则全部等于 `page_start`，而 `page_start==page_end` 是 S3 回链的前提。
- 必须有 `level=0` 的虚拟 root：第一章之前（封面声明、编写组名单）要有地方挂。

### 4.4 T4 · 父子双层切分（ADR-01）

**这一步要解决的问题**：纯章节切分粒度不均（一节 20 字，一节 3000 字含表）；纯定长切分会把剂量表与推荐意见拦腰截断。ADR-01 的答案是**父节点保完整性、子块保检索精度**。

**关键实现思路**

- **父节点 = 完整小节，一行不切**；它只存在于 `parent_id` 与 PG `sections` 里，**不进向量库**（理由见 §5.6 误解部分）。
- **子块目标 200–400 token、硬上限 480**。为什么不追大：`bge-m3` 的句向量是整段池化，800+ token 的块是多主题质心，检索会明显退化；BM25 的 `b=0.75` 长度归一化也系统性压低长块（§5.4 给公式与数字）。480 给表头与续行留余量。
- **语义边界递降**：段落（block 边界 / `\n\n`）→ 中文句末 `[。！？；]` → 逗号 → 硬切。**任何一级都不做 overlap**：医学证据重叠会造出"看似两处证据其实是同一句"的假召回，比漏召回更难排查。
- **`chunk_type ∈ {table, recommendation}` 硬约束**：禁止跨节、禁止跨页合并；超长则单独成块且**每片重复表头**并标 `（续）`。

```python
# src/medevirag/ingest/chunker.py
from __future__ import annotations

import hashlib
import re
import unicodedata
from dataclasses import dataclass

MAX_TOKENS = 480           # 硬上限
MIN_TOKENS = 200           # 目标下界
TAIL_MERGE_TOKENS = 120    # 低于此值的尾块尝试并入前块

_PARA = re.compile(r"\n{2,}")
_SENT = re.compile(r"(?<=[。！？；])")
REC_HINT = re.compile(r"(推荐|建议|应当|不推荐|禁用|首选|一线用药|证据等级|推荐强度|推荐类别)")


@dataclass(slots=True)
class Unit:
    text: str
    kind: str              # body | table | rec
    page: int
    bbox: tuple[float, float, float, float] | None


def make_token_counter(model_path: str):
    """bge-m3 的 tokenizer = XLM-RoBERTa sentencepiece。选它的理由见 §5.3。"""
    from transformers import AutoTokenizer
    tok = AutoTokenizer.from_pretrained(model_path)

    def count(s: str) -> int:
        return len(tok.encode(s, add_special_tokens=False))

    return count


def guess_type(units: list[Unit]) -> str:
    if any(u.kind == "table" for u in units):
        return "table"
    text = "".join(u.text for u in units)
    if REC_HINT.search(text):
        return "recommendation"
    if text.count("、") >= 3 and len(text) < 200:
        return "list"
    return "paragraph"


def to_units(sec_blocks: list, count) -> list[Unit]:
    units: list[Unit] = []
    for b in sec_blocks:
        if b.kind == "table":
            units.append(Unit(b.text, "table", b.page, b.bbox))
            continue
        if b.kind == "figure_caption":
            units.append(Unit(b.text, "body", b.page, b.bbox))
            continue
        for para in _PARA.split(b.text):
            para = para.strip()
            if para:
                units.append(Unit(para, "rec" if REC_HINT.search(para) else "body",
                                  b.page, b.bbox))
    return units
```

```python
def split_long(u: Unit, count) -> list[str]:
    """句子级递降；单句仍超长则按 480 硬切（不加 overlap）。"""
    sents = [s for s in _SENT.split(u.text) if s.strip()]
    out: list[str] = []
    cur = ""
    for s in sents:
        if count(cur + s) <= MAX_TOKENS:
            cur += s
            continue
        if cur:
            out.append(cur)
        while count(s) > MAX_TOKENS:
            cut = _char_budget(s, count)
            out.append(s[:cut])
            s = s[cut:]
        cur = s
    if cur:
        out.append(cur)
    return out


def _char_budget(s: str, count, target: int = 400) -> int:
    """二分找"不超过 target token 的最大字符数"，用于无句读的超长行。"""
    lo, hi = 1, len(s)
    best = 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if count(s[:mid]) <= target:
            best, lo = mid, mid + 1
        else:
            hi = mid - 1
    return best


def split_table_by_rows(u: Unit, count) -> list[Unit]:
    """表格按行组切，每片重复表头并标（续）；绝不跨页（u 本身页内闭合）。"""
    if count(u.text) <= MAX_TOKENS:
        return [u]
    lines = u.text.splitlines()
    head, body = lines[:2], lines[2:]
    head_txt = "\n".join(head)
    out: list[Unit] = []
    buf = list(head) + ["（续）"]
    n = count(head_txt) + count("（续）")
    for row in body:
        rc = count(row)
        if n + rc > MAX_TOKENS and len(buf) > len(head) + 1:
            out.append(Unit("\n".join(buf), "table", u.page, u.bbox))
            buf = list(head) + ["（续）"]
            n = count(head_txt) + count("（续）")
        buf.append(row)
        n += rc
    if len(buf) > len(head) + 1:
        out.append(Unit("\n".join(buf), "table", u.page, u.bbox))
    return out
```

```python
def chunk_section(sec, units: list[Unit], count) -> list[dict]:
    """在父节点内部切子块；返回未补元数据的 chunk dict 列表（页内闭合）。"""
    rigid = any(u.kind in ("table", "rec") for u in units) and len(units) == 1
    groups: list[list[Unit]] = []

    if rigid:                                   # 表格/推荐意见：一单元一块，不合并
        expanded = split_table_by_rows(units[0], count) \
            if units[0].kind == "table" else (
                [Unit(t, units[0].kind, units[0].page, units[0].bbox)
                 for t in split_long(units[0], count)])
        groups = [[u] for u in expanded]
    else:
        cur: list[Unit] = []
        n = 0
        for u in units:
            t = count(u.text)
            if t > MAX_TOKENS:
                if cur:
                    groups.append(cur)
                    cur, n = [], 0
                groups.extend([[Unit(p, u.kind, u.page, u.bbox)]
                               for p in split_long(u, count)])
                continue
            if cur and n + t > MAX_TOKENS:
                groups.append(cur)
                cur, n = [], 0
            cur.append(u)
            n += t
        if cur:
            groups.append(cur)
        groups = merge_tail(groups, count)

    out: list[dict] = []
    for i, g in enumerate(groups, start=1):
        text = "\n\n".join(x.text for x in g)
        pages = sorted({x.page for x in g})
        out.append({
            "chunk_type": g[0].kind if rigid else guess_type(g),
            "text": text,
            "token_len": count(text),            # 必须对拼接后的 text 复算
            "page_start": pages[0],
            "page_end": pages[-1],
            "locator": {"page": g[0].page, "block_index": 0,
                        "bbox": list(g[0].bbox or [])},
            "_seq": i,
        })
    return out


def merge_tail(groups: list[list[Unit]], count) -> list[list[Unit]]:
    """尾块过短则并入前块（仅当合并后不超 MAX_TOKENS）。"""
    if len(groups) < 2:
        return groups
    last = groups[-1]
    if count("\n\n".join(u.text for u in last)) >= TAIL_MERGE_TOKENS:
        return groups
    prev = groups[-2]
    if count("\n\n".join(u.text for u in prev + last)) <= MAX_TOKENS:
        return groups[:-2] + [prev + last]
    return groups
```

`context_header`、`chunk_id`、`content_hash` 与硬约束断言：

```python
def context_header(doc_title: str, section_path: list[str]) -> str:
    tail = section_path[-1] if section_path else ""
    return "《" + doc_title + "》 > " + tail if tail else "《" + doc_title + "》"


def build_chunk_id(doc_id: str, section_no: str, seq: int) -> str:
    no = section_no.replace(" ", "").replace("（", "(").replace("）", ")") or "root"
    no = re.sub(r"[/\\#?&%]", "-", no)          # 主键与 URL 双重要求
    return doc_id + "#" + no + "#c" + str(seq).zfill(2)


def content_hash(text: str) -> str:
    norm = re.sub(r"\s+", "", unicodedata.normalize("NFKC", text))
    return "sha256:" + hashlib.sha256(norm.encode("utf-8")).hexdigest()


def assert_hard_constraints(c: dict) -> None:
    """00 §6.1 三条硬约束的运行时断言，失败即中止本次切分。"""
    if c["chunk_type"] in ("table", "recommendation"):
        assert c["page_start"] == c["page_end"], \
            "table/recommendation 禁止跨页合并: " + c["chunk_id"]
    assert c["token_len"] <= MAX_TOKENS or c["chunk_type"] == "table", \
        "超长且未按行切分保留表头: " + c["chunk_id"]
    assert c["context_header"], "context_header 不能为空: " + c["chunk_id"]
    if c["page_start"] == c["page_end"]:
        assert len(c["locator"]["bbox"]) == 4, "回链 bbox 缺失: " + c["chunk_id"]
```

**坑**

- **`token_len` 必须对 `text` 复算**，不能把子单元 token 数相加——拼接引入 `\n\n` 与标点，相加会系统性少算 3~8%。
- `chunk_id` 含 `/`（如 `A/B`）会破坏 PG 主键与 URL 路径，必须 sanitize。
- 表格跨页时 `page_start != page_end` 直接违反 00 §6.1；**在 chunker 里断言，别指望报告兜底**。
- 空文本、纯页码、纯"目录"块要在入口挡住，不要生成 `token_len=3` 的垃圾 chunk（会污染 S2 的 `avgdl` 与 BM25 打分）。

证据等级：**正则 + 上下文窗口双闸**，缺一不可。

```python
# src/medevirag/ingest/evidence.py
import re
import unicodedata

EVIDENCE_PATTERNS = [
    ("GRADE", re.compile(r"证据(?:等级|级别|质量|体质量)\s*[:：]?\s*([ABCD])(?![A-Za-z0-9])")),
    ("牛津",  re.compile(r"(?:证据水平|证据级别|Level\s+of\s+evidence)\s*[:：]?\s*([1-5])(?!\d)")),
    ("指南自定", re.compile(
        r"推荐(?:强度|级别|类别|等级)\s*[:：]?\s*(III|IIa|IIb|IV|II|I)(?![A-Za-z0-9])")),
]
ANCHORS = ("推荐", "证据", "级别", "等级", "患者", "治疗", "临床", "研究", "质量")
WINDOW = 120


def _window_ok(text: str, start: int, end: int, min_anchors: int = 2) -> bool:
    ctx = text[max(0, start - WINDOW): min(len(text), end + WINDOW)]
    return sum(1 for a in ANCHORS if a in ctx) >= min_anchors


def extract_evidence(text: str) -> dict:
    """返回 {evidence_level, rec_strength, grade_system}；缺失一律 'unknown'。"""
    text = unicodedata.normalize("NFKC", text)
    level, strength, system = "unknown", "unknown", "unknown"
    for name, pat in EVIDENCE_PATTERNS:
        for m in pat.finditer(text):
            if not _window_ok(text, m.start(), m.end()):
                continue                    # 上下文不像在谈证据等级 → 丢弃
            val = m.group(1)
            if name == "GRADE" and level == "unknown":
                level, system = val, "GRADE"
            elif name == "牛津" and level == "unknown":
                level, system = val, "牛津"
            elif name == "指南自定" and strength == "unknown":
                strength = val
                if system == "unknown":
                    system = "指南自定"
            if level != "unknown" and strength != "unknown":
                return {"evidence_level": level, "rec_strength": strength,
                        "grade_system": system}
    return {"evidence_level": level, "rec_strength": strength, "grade_system": system}

## 5. 知识点讲解

### 5.1 字符准确率（CER）与 Levenshtein 距离

**是什么**：`CER = (S + D + I) / N`，S/D/I 分别是替换/删除/插入的字符数，N 是参考文本长度；**字符准确率 = 1 - CER**。

**为什么需要**：PDF 解析质量是 S1 唯一"一坏全坏"的环节。用"看起来还行"判断没有说服力；95% 是 00 §3 定下的换解析器阈值。

**在本项目怎么用**：`char_accuracy()` 先 `NFKC` 归一 + 去掉全部空白再算距离。空白必须去——否则 pymupdf 把段间距识别成不同数量的空格，就会虚降 3~5pp，把本来合格的文档判成不合格。

**常见误解**：以为"抽 3 页"是为了统计显著。不是——它是**劣化探测**：如果某类 PDF（双栏、表格密）的某页 CER 到 8%，这份文档的表格区大概率整体不可用，3 页足够触发换解析器。30 页反而会让 T2 吃掉 4h。

### 5.2 版面分析：从"字符流"到"版面块"

**是什么**：PDF 里没有"段落"和"标题"，只有"在某坐标画某字形的指令"。版面分析就是把这些指令聚成语义块（标题/正文/表格/图注）。

**为什么需要**：章节树重建的唯一输入是"块 + 字号 + 位置"。块切错了，后面全靠拍脑袋。

**在本项目怎么用**：块级字号取**字符数加权众数**而非最大值；表格 bbox 内的文本从正文流剔除（否则同一段内容进两次，chunk 数虚高、BM25 的 `avgdl` 被拉偏）；双栏页按 `(栏序, y0)` 重排。

**常见误解**：以为 `get_text()` 的块顺序就是阅读顺序。多栏、页脚插注、浮动图注都会打破顺序，**必须显式排序**。

### 5.3 token 计数：为什么选 bge-m3 的 tokenizer 而不是 tiktoken

**是什么**：`token_len` 是 chunk 的长度单位，也是 prompt 预算的计价单位。

**为什么需要**：它在本项目干两件事——卡 480 上限、估 S3 的 prompt 预算。两件事都必须和**下游模型的真实切分**一致。

**在本项目怎么用**：选 **`bge-m3` 的 tokenizer（XLM-RoBERTa sentencepiece）**。三个理由：

1. **一致性**：S2 的 embedding 就是 `bge-m3`，用它的 tokenizer 数出来的 480 才是它真正"看到"的 480。用 `tiktoken`（`cl100k_base`/`o200k_base`）数 480 的块，到 `bge-m3` 实测可能 560~620，上限形同虚设。
2. **可解释**：报告里的 `token_len` 与 S2 的 embedding 截断行为同源，出问题能对上号。
3. **中文偏差**：中文没有空格分界，两套 BPE 的合并规则完全不同。`tiktoken` 对中文医学文本常落在 1 字 ≈ 0.6~0.7 token，XLM-R 在术语密集段落常 1 字 ≈ 0.5~0.9 token，**同一段文本两边可差 30%**。差 30% 意味着"400"可能真的是 400，也可能是 560。

**代价与降级**：`transformers` + 权重约 2.2GB，比 `tiktoken`（几 MB）重得多，首次加载约 5s。所以提供 `--tokenizer tiktoken` 作为**开发期临时降级**，并在日志打一行
`WARN: token_len computed by tiktoken, not comparable to bge-m3`；
**最终写进 `chunks.jsonl` 的那一版必须用 bge-m3 tokenizer**，并在文件头写 `"tokenizer": "bge-m3"` 便于追溯。

**常见误解**：以为"token 数差不多就行"。差 20% 意味着 S3 的 prompt 预算会超，或 chunk 被 embedding 静默截断——两种都不会报错，只会让效果莫名下降。

### 5.4 BM25 的长度归一化，反过来说明"为什么必须切小"

**是什么**：BM25 打分公式

```
score(q, D) = Σ_{i=1}^{n} IDF(q_i) · [ f(q_i, D) · (k1 + 1) ] / [ f(q_i, D) + k1 · (1 - b + b · |D| / avgdl) ]
```

其中 `k1 = 1.5`（词频饱和），`b = 0.75`（长度归一化强度），`|D|` 是 chunk 长度，`avgdl` 是平均长度。

**为什么需要**：医学查询里"收缩压 140""eGFR<60""氨氯地平 5mg"这类精确串向量天然弱，BM25 是补丁（00 ADR-02）。但 BM25 对块长高度敏感，而块长是我们自己定的。

**在本项目怎么用**：设 `avgdl = 300`。

- 300 token 的块：`|D|/avgdl = 1`，分母长度项 `k1·(1 - 0.75 + 0.75·1) = 1.5`，满额。
- 3000 token 的父块：`|D|/avgdl = 10`，分母长度项 `1.5·(0.25 + 7.5) = 11.625`，**涨约 7.75 倍**。
- 同样 `f(q,D)` 下，长块的得分约为短块的 **1/6**（当 `f` 远大于分母时趋近于 `11.625/1.5 ≈ 7.75` 倍差距）。

结论：**长块被排到后面不是因为不相关，而是因为太长**。这是"索引必须建在 200–400 token 的子块上、父节点只做证据回填"的量化理由。

**常见误解**：以为 `b` 越大越好。`b=1` 是完全归一化（长块被过度惩罚），`b=0` 关闭归一化（长块靠词频刷分）。0.75 是经验默认值，本项目不改它，改的是自己的块长。

### 5.5 页眉页脚检测 = 重复行统计 + 位置先验

**是什么**：把"在页面顶/底 8% 区域、跨页高重复"的行判为页眉页脚。

**为什么需要**：页眉往往含指南名与年份，会被 `extract_publish_year` 和标题识别**同时误捕**（"中国高血压防治指南 2024"看起来非常像一个一级标题）；页脚含印刷页码，会污染 `page_end` 判定。

**在本项目怎么用**：归一化键 = `NFKC + 数字→# + 去空白`；阈值 `出现页数 ≥ 3 且 出现页数/总页数 ≥ 0.30`。取 30% 而不是 50% 的依据：奇数页/偶数页页眉常左右交替（左页"指南名"、右页"章名"），单向阈值取 50% 会把两边都漏掉；30% 能同时抓住交替版本，又不会被"某章标题恰好每页重复"误伤。

**常见误解**：以为可以按固定坐标删（"y<60 删掉"）。不同出版社版心完全不同，坐标跨文档不可迁移；**跨页频次是唯一跨文档可用的信号**。

### 5.6 small-to-big（父子双层）检索范式

**是什么**：用**小块**建索引做检索（精度高），命中后用它的**父节点**（完整小节）回填给生成层（证据完整）。

**为什么需要**：这是"检索精度"与"证据完整性"矛盾的正解。纯大块：embedding 是多主题质心，检索不准，且 BM25 按 §5.4 惩罚它。纯小块：检索对了，但生成时看到半句话不足以支撑结论。

**在本项目怎么用**：子块目标 200–400 token（中位目标 300），父节点=完整小节（中位约 900 token）。S3 里 `rerank Top8 → 取去重后的父节点，只回填前 3 个`，prompt 增量 `3 × 900 ≈ 2700` token；加 8 个子块的引用列表约 1.5k，总上下文约 6k，远低于生成窗口。**回填必须按 `parent_id` 去重**：Top8 常全落在 2~3 个父节点里。

**常见误解**：以为父节点也要进向量库。本项目**不给父节点建向量**——父节点的角色是"生成时的证据容器"，检索完全交给子块。多建一份只会让候选池混进大块，破坏 §5.4 的长度假设，并稀释 §6 的 `token_len` 分布统计意义。

### 5.7 证据等级体系（GRADE / 牛津 / 推荐强度）

**是什么**：三套常被混用的东西：

- **GRADE 证据质量**：A（高）/B（中）/C（低）/D（极低），评"证据体"的可信度；
- **牛津 CEBM 证据水平**：Level 1~5，评**研究设计**（RCT > 队列 > 病例对照 > 病例系列 > 专家意见）；
- **推荐强度**：I / IIa / IIb / III（ESC/AHA）或 Class I~III，评"该不该做"，**与证据质量不是一回事**。

**为什么需要**：S4 的拒答规则有一条"证据等级不达标则降级或拒答"，它需要一个确定的三元组 `(evidence_level, rec_strength, grade_system)` 才能判。

**在本项目怎么用**：三者**分开存三个字段**（00 §6.1 就是这么定的）。`grade_system` 记录"这条等级是哪套体系给的"——否则 `"B"` 到底是 GRADE 的 B 还是别的体系，无法解释、无法审计。

**常见误解**：以为"证据等级 A" = "强推荐"。完全可能"高质量证据支持不做某事"（GRADE A + 推荐 III）。把两者合成一个字段，S4 的规则表根本写不出来。

### 5.8 数据分区与幂等重放（raw / interim / processed）

**是什么**：`raw`（不可变原始件）→ `interim`（可重算的中间态：blocks/sections JSON）→ `processed`（对外契约：chunks.jsonl）。

**为什么需要**：调 chunker 参数时不该重下 PDF、不该重解析；调 sectionizer 时不该重跑 parser。每层可单独 `--force` 重算，这是 20h 预算内能反复调参的前提。

**在本项目怎么用**：`content_hash`（归一化文本的 sha256）是增量索引的键——S2 里"文本没变的 chunk 不重算 embedding"。这也是为什么 `content_hash` 必须对**归一化文本**算（NFKC + 去空白）：否则改一个空格就全量重算（1247 个 chunk × bge-m3 约 40s，可接受；10 万级就不可接受了）。

**常见误解**：以为 `interim` 可以随时删。删了之后 `sections.json` 里的 `page_offset` 与目录校验结果要重算，人工核对记录（30 条抽样表）会丢——它比 `processed` 更贵。

## 8. 面试可讲点

1. **"我把章节树当成一等公民，chunk 只是它的叶子。"**
   我做了什么：先建 `sections` 树（编号正则 + 字号 + 目录三路证据，栈装配 + `page_end` 回填），再在树上切子块。
   为什么这么做：被否决的方案是"固定 512 token 切分"——剂量表与推荐意见会被拦腰截断，答案必然失真；而"纯章节切分"粒度从 20 字到 3000 字不均，embedding 会退化成多主题质心。父子双层同时要到两头的收益。

2. **"页眉页脚我没有硬编码坐标，用的是跨页重复行统计。"**
   我做了什么：只在页面顶/底 8% 采样，数字归一成 `#`，出现页数 ≥3 且占比 ≥30% 即剔除。
   为什么这么做：坐标在不同出版社之间完全不通用，跨到第二份文档就崩。30% 而不是 50%，是为了同时抓住奇偶页交替的左右页眉——取 50% 会漏掉一半。

3. **"表格 chunk 不跨页不是靠约定，是靠运行时断言。"**
   我做了什么：`assert page_start == page_end`，超长按行组切且每片重复表头并标 `（续）`。
   为什么这么做：跨页表格拼起来后 `bbox` 跨两页，API 就无法做"回链到页 + 高亮段落"，可溯源直接失效。用断言把它变成硬失败，比事后写报告靠谱——报告可以忘记写，断言不会。

4. **"token 数我用 bge-m3 自己的 tokenizer，不用 tiktoken。"**
   我做了什么：`AutoTokenizer.from_pretrained("models/bge-m3")` 计数，480 硬上限，对拼接后的 `text` 复算。
   为什么这么做：用 tiktoken 数出来的 480，到 bge-m3 实测可能是 560~620（中文无空格分界，两套 BPE 规则不同，差 30%），上限形同虚设，S3 的 prompt 预算会超。代价是多下一个 2.2GB 权重，所以留了 `--tokenizer tiktoken` 仅作开发期降级并打 WARN。

5. **"证据等级可得率只有 20%~40%，我如实报，而且这正是 unknown 分支的立项依据。"**
   我做了什么：GRADE / 牛津 / 推荐强度三套正则 + ±120 字上下文窗口双闸，缺失写 `"unknown"` 不写 `null`，按 chunk 与按文档两口径统计。
   为什么这么做：中文指南多数不给 GRADE。如果我假装覆盖率 90%，S4 那句"证据等级不达标则拒答"会因为没有等级可用而全量误拒——过度拒答率直接爆掉 00 §9 的 ≤0.12。诚实把 `unknown` 做成独立降级规则（不直接拒、也不直接放行）才是可审计的设计。

6. **"为什么切小还要保留父节点：BM25 的长度归一化会惩罚长块。"**
   我做了什么：子块 200–400 token 建索引，父节点（完整小节，中位约 900 token）只在生成时按 `parent_id` 去重后回填前 3 个。
   为什么这么做：`b=0.75` 下，3000 token 的块相对 `avgdl=300` 的分母长度项涨约 7.75 倍，得分掉到约 1/6——**长块排在后面不是因为不相关，而是因为太长**。这条量化理由就是"索引必须建在子块上"的根据。

### 10.3 与后续阶段的交接点

- **交接给 S2**：`chunks.jsonl` 的 `chunk_id / text / context_header / content_hash / token_len` 五个字段是 embedding 与 BM25 的输入契约；改名必须 S2 同步改。
- **交接给 S3**：`locator.page` + `bbox` 是引用回链的唯一依据，必须 100% 非空；`parent_id` 是 small-to-big 回填的键。
- **交接给 S4**：`evidence_level / rec_strength / grade_system` 三字段与可得率报告，是 `unknown` 降级规则的输入与立项依据。
- **交接给 S5**：`doc_type / publish_year / lang / publisher` 是评测集分层抽样的分层变量（12 个疾病主题 × 文种 × 年份）。
