## 1. 简历四条（数字均已实测）

1. **搭建中文医学循证问答系统（MedEviRAG）**：以 LangGraph 8 节点图编排"路由→改写→混合召回→过滤→重排→生成→校验→判定"全链路，每问输出带 `[C1]` 可点引用的答案，引用可回链到指南原文页码与 bbox 坐标；20 并发压测 **P95=1.9s**（预算 6s），零错误率。

2. **两级引用校验 + 17 条可审计拒答规则**：落点校验拦住模型编造的引用标记（注入测试 0 漏过），句级 bigram 蕴含校验控制支撑率；17 条规则（越界/时效/个体化用药/证据不足四类）带稳定执行序与 54 条夹具矩阵，拒答召回 **1.00**、过度拒答 **0.00**、理由正确率 **1.00**（夹具级），理由可通过 `rule_id` 追溯到具体阈值。

3. **用数据否决了重排**：在 60 题标注集上做 K=10/20/50 三档扫描，最优档 ΔMRR=0.056 低于 0.10 采用门槛，按预案改直通并留全档数据与理由——比"接上就算完成"少 200-550ms/问的延迟开销。

4. **从语料到服务的全链路工程**：4023 个章节感知 chunk（表格/推荐意见整块保留），RRF 融合双路召回 Recall@10 达标；160 题分层评测集（12 主题×3 题型，冻结戳防篡改，改 gold 一行即被拦截）；FastAPI 五端点服务化含两级缓存与审计日志；全仓 **ruff/mypy(strict) 0 错误 + 317 条测试全绿**。

## 2. 面试问答

### Q1 · 为什么要做引用校验？Prompt 不是已经写了"必须引用"吗

**精炼版**：Prompt 是概率手段，只能提高"带引用"的似然，没有下界；校验是判定手段，结果与模型心情无关。医疗场景必须能回答"模型编了引用怎么办"——答案是"编的引用不会出现在返回结果里"。

**详细版**：实测 FakeLLM 注入 `[C9]`（越界标记），校验链把它从答案里删掉或整句删除，最终输出中 `[C9]` 出现 0 次；两轮全非法时 LLM 调用被硬上限压在 2 次。两级校验：①落点——每个标记必须能在本次召回集合找到对应 chunk；②句级蕴含——该句挂的 chunk 原文要能支撑该句。校验失败走六级降级策略表（删标记→删句→重试一次→拒答），而不是"给个提醒"。

### Q2 · 重排器为什么没用上？

**精炼版**：不是没做，是做了之后**用数据否决了**。ΔMRR=0.056 < 0.10 的采用门槛，每问白花 200-550ms 不值。

**详细版**：在 60 题标注集上跑 K=10/20/50 三档，B0 基线 MRR@8=0.813，三档分别 0.858/0.869/0.867——增量只有 0.044-0.056，且 K=20 与 K=50 几乎重合（边际收益差 <0.01）。bge-m3+RRF 基线已经把 Top8 命中率做到 0.95，重排的天花板被压死了。按预案走"否决"分支：配置开关置 false、节点直通、重排器代码保留可随时开回，全程留档不凑指标。这比"接上就算完成"更有工程判断力。

### Q3 · 检索为什么用 RRF 不用加权融合？

**精炼版**：余弦是 [-1,1]、BM25 是 [0,+∞)，量纲不可比；RRF 只用名次，天然免疫量纲问题且免调参。

**详细版**：加权融合要做 min-max 归一化，alpha 权重是调参旋钮，会在不同分布的 query 上漂。RRF 的 score = Σ 1/(k+rank)，k=60 一个参数对全量数据集一次定死。加权融合在项目里作为消融对照保留（s2_ablation 可复跑），生产路径是 RRF。

### Q4 · 置信度为什么不用向量相似度？

**精炼版**：相似度衡量"主题接近"不是"能回答"；长文本 mean pooling 有 length bias；跨 query 不可比，单一阈值必然一边狂拒一边狂放。

**详细版**：项目里置信度是四分量加权：排序分（top1 的 Platt 标定分）+ 引用覆盖率（挂了合法引用的断言句比例）+ 证据等级加权 + top1/top5 分差。排序分的 Platt 参数不是拍脑袋：在 60 题上以"top1 是否命中 gold"做二分类标签，网格搜最小化 logloss 定标（0.5029 vs 常数基线 0.5799）。重排否决后排序信号自动切到 dense 余弦口径，参数按同法重标——两套参数并存于配置，开关一拨自动切换。

### Q5 · 评测集怎么防"调参调到 test 集上"？

**精炼版**：80/20 分层划分 + 冻结戳。test 集成员的哈希写进 freeze.json，跑 runner 先校验，改一行 gold 立刻退出非 0。

**详细版**：指纹只含 case_id 和 gold（故意不含 question 文本——改错别字不应让历史报告作废，代价是改问句靠 PR review 兜底）。test 子集跑评测必须显式 `--allow-test`。CI 的验收脚本现场演示"篡改→exit 1 + FREEZE_MISMATCH→恢复→exit 0"。160 题按 12 主题×3 题型（90 可答/50 应拒/20 多跳）分层配额，应拒再分四类（越界 12/时效 10/个体化 16/证据不足 12）——个体化给最多，因为它最容易被模型"好心"答错。

### Q6 · 拒答规则怎么保证不误伤合法问题？

**精炼版**：个体化类全部双条件（人称/所有格 **且** 剂量或决策动词），宁可漏判不误判；20 条边界题专门防误拒。

**详细版**："氨氯地平常用剂量是多少 mg"（无主语，循证合法）与"我该吃多少 mg"（个体化，必拒）字面只差人称。规则要求双条件同时命中才拒。落地时 docs 自己给的示例句在原版正则下不命中，逐条补了分支并用反例回归（"孕妇可以吃对乙酰氨基酚吗"这类合法问句不误拒）。54 条夹具跑出来的过度拒答率是 0.00。

### Q7 · 服务化的缓存为什么把答案和引用一起存？

**精炼版**：分开存会出现"答案命中、引用过期"——用户看到 [C1] 点开是 404，回链断裂。

**详细版**：答案缓存 value 整体序列化 answer+citations+status+confidence+disclaimer+refusal_reason 六字段，命中时响应结构与非命中完全一致。拒答也缓存（确定性输出，TTL 减半防规则更新后旧拒答滞留）。缓存 key 含 config_hash——改配置/prompt 后 key 自然不命中，不用手工清库。实测第二次命中 <200ms 且 citations 逐元素相同。

### Q8 · 全链路可观测怎么做？

**精炼版**：trace_id 从 HTTP 头一路带到审计日志与响应头；图内 8 节点逐点埋点耗时；每问一条 qa_log 落四段耗时 + 参与 chunk 列表。

**详细版**：节点耗时基于父状态拷贝累加（否则节点间互相覆盖只剩一个）；qa_log 写"参与生成的全部 chunk_id"而不只 Top8——排查"为什么没选它"需要的是没入选的那批。无 PG 环境降级写 jsonl，写失败只记日志绝不拖垮响应。

## 3. 关键知识点（一句话版）

| 知识点 | 一句话解释 | 本项目落地 |
|---|---|---|
| bi-encoder vs cross-encoder | 双编码器离线算 doc 向量在线 O(1) 次前向；交叉编码器每次打分全量前向，只能放在漏斗末端 | bge-m3 召回 50 → reranker 排 8 |
| RRF | 只用名次融合，免疫分数量纲 | k=60，两路 50 并 |
| recall ceiling | 重排只能重排已有候选，命中率硬上界 = 重排前 Recall@K | 实测被 0.95 的基线天花板压死 |
| small-to-big | 子块负责被检索到，父块负责被读懂；父块不编号防"引用整节" | 父块全文进 prompt 只作上下文 |
| LLM-as-judge 偏差 | 位置偏差/长度偏差/自我偏好 | 证据乱序 + 跨族断言（生成 DeepSeek 判分 Qwen） |
| Cohen κ | 一致率要扣掉随机一致的底 | 标注流程按 (case, chunk) 对展开成二分类 |
| ECE | 置信度分箱后 |acc-conf| 加权 | S5 报告实测输出，不设硬门禁 |
| bootstrap CI | 有放回重采样给指标置信区间 | 每个 gated 指标带 95% CI |
| 就绪 vs 存活探针 | healthz 只证明进程活着，readyz 证明依赖齐 | 四项并发探测，2s 单项超时 |
| Milvus Lite 文件锁 | 本地单写者，孤儿进程持锁会崩掉后续所有检索 | 验收脚本 taskkill /T 杀进程树 + 跑前清端口 |
